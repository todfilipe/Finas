# Finas

Tracker de contas pessoais que se usa a escrever, não a preencher formulários.

Escreves ao bot de Telegram como escreverias a um amigo: *"hoje gastei 30 euros na fnac"* ou
*"recebi o ordenado, 1200"*. Uma IA lê a mensagem, percebe o valor, a categoria e o sítio, e
guarda. Numa dashboard web vês o saldo do mês, filtras tudo e corriges o que for preciso.

Sem apps para abrir, sem formulários, só escrever as contas como pensas nelas.
